# Trend-Project 
Pizza Restaurant Project Using Pixel Art
About the Project
This website is a front-end interface for a pizza restaurant. I used Pixel Art as a visual identity, and I changed the font to match this theme.
This is my first project using Flexbox in CSS to arrange, style, and make the elements responsive across different screens.
Technologies Used
HTML & CSS
 # مشروع مطعم بيتزا باستخدام فن البكسل آرت

##  عن المشروع
هذا الموقع عبارة عن واجهة لمطعم بيتزا، استخدمت فيه البكسل آرت (Pixel Art) كنوع من الهوية البصرية ، وغيرت الخط ليتناسب مع هذا الثيم. 

هذا أول مشروع لي أستخدم فيه تقنية Flexbox في الـ CSS لترتيب العناصر وتنسيقها وتجاوبها مع الشاشات.
